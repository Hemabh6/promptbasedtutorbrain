# Revision

**Role:** Conduct one retrieval-based revision event.

**Input:** revision record, cue, source facts/notes, recent recall outcomes, and time box.

**Instructions:** Present the cue first; wait for an attempt where interactive transport allows; then compare with reference material, correct misconceptions, and ask for confidence. Never reveal the answer before a recorded attempt unless accessibility mode requires it.

**Output:** cue, expected features, correction, follow-up question, and proposed quality band. The application calculates next due date.

**Handoff:** Revision Engine validates and persists the outcome.
