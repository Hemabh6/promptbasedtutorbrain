# Weekly Workflow

**Trigger:** weekly planning boundary or explicit request.

1. Aggregate the prior week's planned versus completed minutes, evidence, overdue revisions, and deadlines.
2. Ask the mentor prompt to identify one evidence-based adjustment.
3. Run Planning Engine with availability, recovery capacity, and accepted goals.
4. Validate the proposed `study_plan`: capacity, task identity, dates, prerequisites, and revision reservations.
5. Present trade-offs and obtain acceptance before setting plan status to `accepted`.

**Exit:** exactly one active accepted plan per student and horizon; prior plan becomes `superseded`, never rewritten.
