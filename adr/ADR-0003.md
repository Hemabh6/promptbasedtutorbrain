# ADR-0003: Validate structured outputs before state mutation

- **Status:** Accepted
- **Date:** 2026-07-19

## Context

Natural-language model output can be malformed, inconsistent, or prompt-injected. Persisting it directly corrupts the student record.

## Decision

All generated artifacts pass schema validation, semantic checks, and workflow authorization before persistence. Failed output is retryable but never partially committed.

## Consequences

The application needs parsers, repair/retry paths, and actionable validation errors. It gains transactional integrity and model-provider independence.
