# ADR-0002: Use append-only learning evidence with derived summaries

- **Status:** Accepted
- **Date:** 2026-07-19

## Context

Mastery, feedback, and schedules change as new evidence arrives. Overwriting the evidence makes recalculation and dispute resolution impossible.

## Decision

Store validated learning events as append-only records. Treat profile mastery, retrieval indexes, and plan summaries as versioned derived views with source references.

## Consequences

Storage and projection logic increase, but auditability, recalibration, and correction improve. Deletion requests must erase both source and derived records.
